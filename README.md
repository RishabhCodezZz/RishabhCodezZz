### 🚀 Featured Work

**[ARGUS](https://github.com/RishabhCodezZz/ARGUS)** — Multi-agent LLM system for automated financial due-diligence
An 11-agent hierarchical system on Google's Agent Development Kit (ADK) with runtime orchestration, parallel tool-calling agents, and a code-execution agent that computes financial metrics in real Python/pandas rather than LLM estimation. Includes a deterministic groundedness verifier, a human-in-the-loop approval gate for low-confidence outputs, and 4 guardrail callbacks for prompt-injection defense. Backed by a custom 8-scenario evaluation harness and 90 automated tests.

**[NutriBot (NutriRAG-ML)](https://github.com/RishabhCodezZz/NutriBot-RAG)** — Multilingual RAG for personalized diet recommendations
A Retrieval-Augmented Generation pipeline (Python/Flask) combining ChromaDB vector search, all-mpnet-base-v2 embeddings, and cross-encoder reranking to ground Gemini responses in a 74-item food knowledge base across English, Hindi, and Telugu. Achieved a 1.6% hallucination rate with 0% safety violations across a 48-case evaluation harness. Published at CML 2026, Springer (Scopus-indexed).

**[Docling](https://github.com/docling-project/docling)** — Open-source contributor, IBM Research
Root-caused and fixed a hyperlink-extraction regression dropping URLs across ODT paragraphs, headings, and list items ([PR #3949](https://github.com/docling-project/docling/pull/3949), merged). Shipped through 3 rounds of maintainer review with zero regressions across 44 passing tests.
